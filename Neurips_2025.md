***Foundation of Reasoning in Language Models workshop***
https://neurips.cc/virtual/2025/loc/san-diego/workshop/109559

Test time scaling talk
- Talks about how model performance gets better with increasing number of generations from the model.
- Best of N basically and shows scaling law for model performance getting better with k.
- The increasing number of verifiers also help with improving model performance
- Second part covers training on synthetic data generated by test time scaling generations
- Cartridges is an interesting technique to precompute long documents where using self study a compressed KV cache is pre-computed for every document and then reused during inference.
- SwiRL is a very nice paper showing ways to generate multi-step tool reasoning data. It uses process filtering via LLM judges to filter trajectories that are of low quality. Not just filtering on bad outcomes. At every step model is asked to make a tool call or generate the response using the data is has so far. LLM judges are heavily used for filtering.

OpenThoughts: Data recipe for reasoning models
- Claims to be one of the best datasets for reasoning models
- https://huggingface.co/datasets/open-thoughts/OpenThoughts3-1.2M
- Describes the full pipeline for question generation, answer generation and filtering/dedupe steps.
- Nice ablations done showing the downstream impact of each of the pipeline decisions on impact of data on downstream tasks
- Generating multiple answers for a question is more useul for training than generating distinct (question, answer) pairs.
- For question sources, they find that question diversity is not super important though, selecting the best questions from top sources and getting diverse answers is a good option.
- This data can be used in nano_rl.
- Both chain of thought and answer are produced from the teacher models, multiple teachers are used.

Learning composable chains of thoughts: https://arxiv.org/pdf/2505.22635
- Demonstrates how we can make the model learn composable skills given we have data for atomic skills.
- Adds prefix tags along with random letters and suffix tag with actual cot to simulate complex cot. Also uses prefix tags for some samples which only include atomic CoT. With prefix tag with random letters model learns to ignore irrlevant data and generate compositional CoTs.
- Can be a good way to augment data.
- Uses model merging to combine the models learnt from individual skills.
