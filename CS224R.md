***Lecture 1: Intro to MDPs***
Slides: https://cs224r.stanford.edu/slides/01_cs224r_intro_2025.pdf#page=2.00
- Sequential decision making problems
- In RL, we learn the policy from data pi(a/s)
- Enables learning more than learning from supervised (x,y) pairs data.
- Key attributes of a MDP
    - states
    - observations
    - actions
    - rewards
- If we have observations only and no states, next action depends on all previous observations. If we have states, then only the current state is sufficient. Observation is derived from state, but sometimes only observations are available. Like in chatbots, we see the current question we ask the model (observation), model response needs to consider previous turns as well.
- A sequence of states and actions constitutes a trajectory (s1, a1, s2, a2 ...)
- Next State depends on current state and action and not on previous states or actions (Markov property)
- In neural network we learn the policy that helps us predict action for a given state.
- Goal of RL is maximize sum of rewards over the whole trajectory -> we learn the policy that helps us achieve this.
- Value function: expected reward where you follow a policy pi and start from state s (v(s))
- Q function: expected reward where you follow a policy pi and start from state s and take action a, after this you follow policy pi.
